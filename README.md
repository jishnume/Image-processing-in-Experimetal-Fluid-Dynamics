# Image-processing-in-Experimetal-Fluid-Dynamics

## About this repository
Here, I have described some of the common image processing techniques to analyse fluid dynamics experiments.


### A brief plan for the lessons
0. Getting started with MATLAB
1. Installing MATLAB
2. About Images
3. Inspecting everything about Images - with livescript
4. Intensity transformations - imadjust, histogram - with livescript
5. Spatial filtering - with livescript
6. Image segmentation - edge-detection, thresholding - with livescript
7. Representation and description - based on regionprops, etc.  - with livescript
8. Applying all these knowledge to find sedimentation velocity of a soft particle. - with functions and livescripts
9. Finishing remark
