# Image-processing-in-Experimetal-Fluid-Dynamics

## About this repository
A repository that presents a simple introduction to image-processing using MATLAB.


### Brief plan for the topics

A hands-on course that takes you from installing MATLAB to measuring the sedimentation velocity of a solid particle from images.

| Lesson | Topic |
|:------:|-------|
| [00](docs/lesson_00/) | MATLAB vs Python - key difference |
| [01](docs/lesson_01/) | Installing MATLAB toolboxes |
| [02](docs/lesson_02/) | What is an image ? |
| [03](docs/lesson_03/) | Reading Images and Videos |
| [04](docs/lesson_04/) | Image Enhancement |
| [05](docs/lesson_05/) | Image Segmentation |
| [06](docs/lesson_06/) | Project - Sedimentation of a sphere |
